# 家长学习管理台

一个面向家长的单孩学习与成长管理系统。项目从“每天先看日程”出发，把固定辅导班、每日任务、复盘、身体记录、运动积分和奖励兑换放在同一个网页版里，方便家长持续跟进孩子的学习节奏。

## 主要功能

- 日程安排：主页优先展示今日星期、固定课程、今日任务、完成率和积分。
- 每日任务：按日期、时间段、科目和状态管理任务，支持复制到明天、完成等级和自动积分。
- 固定课程：维护每周重复辅导班，遇到临时变化时可生成当天任务。
- 每日复盘：结构化记录完成情况、完成程度、学习状态、主要问题和明天调整。
- 身体运动：记录身高体重、趋势图、TDEE 与营养估算、运动项目和运动建议。
- 积分奖励：根据任务完成等级和运动积累积分，由家长设置可兑换奖励。
- App 化界面：暖白背景、移动端底部导航、橙/粉/青点缀，适合家长手机端快速查看。

## 技术栈

- React 18
- Vite
- Tailwind CSS
- Vitest
- Testing Library
- lucide-react

## 本地运行

```bash
npm install
npm run dev
```

默认开发地址通常是：

```text
http://127.0.0.1:5173/
```

## 验证命令

```bash
npm test -- --run
npm run build
```

## 当前定位

这是一个前端 MVP，数据暂存在浏览器本地存储中，适合先打磨功能体验和家长使用流程。后续可以继续接入账号系统、云端数据库、课程资源搜索和多孩子管理。
