# 家长学习管理台 MVP 设计

## 背景

这个项目是一个面向家长的学生学习信息管理系统。第一版只服务一个孩子，不做学生端、不做账号权限、不接外部课程搜索，目标是先做出一个家长每天可以打开使用的网页版管理台。

参考项目 `C:\Users\wangjunyi\Desktop\agile-project-app-master` 的形态是 React + Vite + Tailwind 的管理系统，包含侧边栏、多页面、看板、日程、报告等模式。新系统会借鉴它的管理台结构和清晰状态表达，但业务会完全换成学习日程与任务管理。

## 产品目标

第一版解决家长的两个核心问题：

1. 打开系统后，立刻知道孩子今天和本周的学习安排。
2. 能布置、查看、调整每日学习任务，并沉淀每日复盘。

## 范围

### 第一版包含

- 单孩子管理。
- 网页版前端应用。
- 浏览器本地数据保存。
- 日程安排首页。
- 每日任务管理。
- 固定课程管理。
- 每日复盘记录。

### 第一版不包含

- 登录、账号、权限。
- 多孩子切换。
- 学生端。
- 后端数据库和多设备同步。
- B站、名师名课等外部搜索接入。
- AI 自动分析或自动生成计划。

## 信息架构

应用采用左侧导航加右侧工作区的管理系统布局。

导航包含：

- 日程安排
- 每日任务
- 固定课程
- 每日复盘

默认进入 `日程安排` 页面。

## 页面设计

### 日程安排

日程安排是首页，采用“今天 + 本周”的混合布局。

页面上半部分：

- 左侧为今日时间线，按时间顺序展示当天安排。
- 右侧为本周固定课程，展示每周重复的辅导班和固定学习安排。

页面下半部分：

- 今日任务摘要：总任务数、已完成、未完成、待复盘。
- 待处理提醒：未完成任务、今天需要填写复盘、临时事项。

日程安排页的重点是帮助家长快速判断“今天怎么排、现在有没有漏掉的事”。

### 每日任务

每日任务是执行中心。

任务按时间段组织：

- 上午
- 下午
- 晚上
- 其他

每个任务包含：

- 标题
- 科目
- 状态：待完成、进行中、已完成、待复盘
- 优先级
- 预计时长
- 备注

页面支持：

- 新增任务
- 编辑任务
- 删除任务
- 勾选完成
- 按科目筛选
- 按状态筛选
- 查看当天任务统计

### 固定课程

固定课程用于维护每周重复出现的辅导班或固定学习安排。

每条固定课程包含：

- 课程名称
- 科目
- 星期
- 开始时间
- 结束时间
- 地点或上课方式
- 备注

固定课程会在日程安排首页的本周区域展示。第一版先不自动生成每日任务，只作为日程信息展示。

### 每日复盘

每日复盘用于沉淀家长对当天学习状态的观察。

每条复盘包含：

- 日期
- 今日完成情况
- 学习状态
- 主要问题
- 明天调整
- 家长备注

第一版支持新增、编辑、删除和按日期查看复盘记录。

## 数据模型

第一版使用浏览器本地存储保存数据。

核心数据包括：

- `tasks`：每日任务。
- `recurringCourses`：固定课程。
- `reviews`：每日复盘。
- `settings`：孩子姓名、默认科目等基础设置。

数据不需要联网。后续升级数据库时，再把这些结构迁移到后端。

## 交互原则

- 家长打开系统后首先看到日程安排。
- 新增任务要足够快，避免复杂表单。
- 状态变化要明确，完成情况要能一眼扫到。
- 日程、任务、复盘之间保持关联，但第一版不做复杂自动化。
- 所有页面都使用真实业务文案，不做营销式落地页。

## 视觉方向

整体是清晰、稳重、可扫描的家长端管理系统。

视觉参考现有敏捷项目管理系统的侧边栏、多页面和卡片式结构，但降低装饰感，突出日程、任务、状态和提醒。色彩避免过度单一，主色用于关键操作和状态提示，辅助色用于不同科目或任务状态。

## 验收标准

- 打开网页后默认进入日程安排页。
- 日程安排页能同时看到今日时间线和本周固定课程。
- 每日任务页能按时间段管理任务，并支持科目和状态筛选。
- 固定课程页能维护每周重复课程。
- 每日复盘页能记录和查看复盘。
- 刷新页面后，本地保存的数据仍然存在。
- 界面在桌面浏览器和手机宽度下不出现明显重叠或溢出。
