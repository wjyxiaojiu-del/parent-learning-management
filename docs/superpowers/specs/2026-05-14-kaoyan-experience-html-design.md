## Goal

Create a 20-minute HTML presentation for a broad postgraduate exam audience, using the user's verified exam result and daily review notes as evidence.

## Content Positioning

The deck is a method-oriented talk, not a personal story. The user appears as a case study: late-July formal start, final score 341, rank 14/138, with clear lessons from the 414/339 contrast, daily review habits, resource filtering, and tool use.

## Deck Structure

The HTML deck will contain 12 slides:

1. Cover with score, rank, and source credibility.
2. Why this case is useful for a broad audience.
3. The core closed-loop model.
4. Stage 1: recovering learning ability.
5. Stage 2: reinforcement and correction.
6. Stage 3: sprint and prioritization.
7. Daily time-management template.
8. Professional-course learning loop.
9. English and politics strategy.
10. Tools and resource system.
11. Avoidance checklist.
12. Next-day action checklist.

## Visual Direction

Use the Blue Professional palette:

- Background: `#FDFAE7`
- Primary accent: `#1E2BFA`
- Text: `#111111`
- Muted text: `#6B6B6B`
- Display font: Space Grotesk
- Body font: Inter

The page should feel like a polished method report: calm, credible, and compact. Each slide must stay below five main points.

## Interaction

The deck will be a static HTML file with:

- Left/right arrow keyboard navigation.
- Slide counter and progress bar.
- Speaker notes toggle for presenting notes.
- Responsive layout for desktop and narrow screens.
